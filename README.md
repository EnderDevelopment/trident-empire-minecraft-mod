# Trident Empire

Trident Empire is a Minecraft Bedrock Edition mod that adds a detailed royal civilization with a grand palace, military facilities, and a large surrounding city. It also includes the Golden Trident, a signature weapon that grants unique abilities when held in the main hand. The mod is designed for Minecraft version 1.26.52 and is compatible with Android platforms.

## Install

1. Download the `.mcaddon` or `.mcpack` file from the GitHub repository.
2. Open Minecraft Bedrock Edition on your Android device.
3. Tap the three dots in the top-right corner and select "Add-Ons."
4. Tap the "+" button in the top-right corner and select "Add-On from File."
5. Navigate to the downloaded file and select it.
6. Tap "Open" to import the add-on.
7. Ensure the add-on is enabled by toggling the switch next to it.

## Use

1. Spawn the Trident Empire civilization by using the appropriate command or structure block.
2. Explore the detailed royal capital, which includes a gigantic golden royal palace, military facilities, and a large surrounding city.
3. Obtain the Golden Trident by crafting it or finding it in the game world.
4. Hold the Golden Trident in your main hand to activate its unique abilities.
